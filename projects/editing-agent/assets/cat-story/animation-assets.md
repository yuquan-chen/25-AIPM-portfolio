# Pixel cat animation assets

Generated with the built-in image generation tool on 2026-10-07. User-provided sleep and training storyboards were style references, not final scene frames.

- `cat-motion-atlas.png`: transparent character sheet; four run poses, four sleep poses, shocked / determined / slim / awake poses.
- `room-stages.png`: two empty environments, bedroom and treadmill room.
- Runtime: `../../animated-cat.js`. Source PNGs remain intact. Browser compositing selects sprite rectangles and advances poses using the editor clock. Nose bubble, rising z letters, sweat, belt motion, mirror and scale are separate rendered elements. Titles and captions are provided exclusively by text-track clips.
