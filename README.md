## 本地运行

先在终端进入克隆下来的仓库根目录（也就是包含 `index.html` 的目录），再启动静态服务器。无需安装依赖。

Windows：

```powershell
py -m http.server 8780
```

macOS / Linux：

```bash
python3 -m http.server 8780
```

然后在浏览器打开 <http://127.0.0.1:8780/>。结束运行时，在终端按 `Ctrl+C`。
