# Notes drawer motion

This isolated build adds a physical drawer to `cover-preview.html`. The rest of
the portfolio is still a static site; visitors do not need Node or a video player.

- `scene.js`: common SVG geometry and Remotion `spring()` timing at 60 fps.
- `browser.js`: closed → file tabs → selected file interaction, focus and keyboard controls.
- `DrawerComposition.jsx`: Remotion composition `NotesDrawerPull`, 800 × 650, 192 frames.
- `../../scripts/notes-drawer.js`: checked-in browser bundle generated by esbuild.

Run `npm ci` and `npm run build` from this directory after changing the source.
Serve the portfolio root and open `cover-preview.html` to try the interaction.
The composition can be used in Remotion Studio or its renderer. It shares the
same geometry and spring curve as the live drawer. A rendered video is optional
and is not needed by the webpage.

The original essay content and diagrams remain in `scripts/llm-journey.js`.
The file stack uses short labels; essay headings are preserved inside each file.
Click the open file's title tab to slide it back into the stack.
Escape also slides the selected file back, and a second Escape closes the drawer.
Reduced-motion preferences skip the animation. Rapid reversal starts from the
current position instead of resetting the drawer to an endpoint.
